# Prototipo musica nativa

Il prototipo Android reale e la guida italiana sono nella cartella
[experiments/zepp-music](../../../experiments/zepp-music/README.md) del repository.

E' un'app di prova separata dalla SyncBeat Flutter normale, sul branch
`experiment/zepp-native-music`. Non richiede di cambiare main o disinstallare
l'app abituale. Leggi la guida prima di tentare un collegamento: la compatibilita'
sul firmware dell'Active 3 Premium non e' ancora verificata sul dispositivo.
